# Pomato Radio 130.3

A 24/7 station with a human host. The day is seven named shows; music and
talking both follow the clock, and the host ducks the music instead of
interrupting it.

**Everything the station needs lives in this folder.** Nothing references
`~/Downloads`, `/tmp`, or any system config — put new recordings and artwork in
`sources/` and the project stays portable.

```
start.sh              brings up icecast + station + player in one command
station.liq           the station: playlists, dayparts, ducking, live mic
persona.md            who the host is — the whole personality lives here
schedule.json         the seven shows: names, hours, and what each sounds like

scripts/
  clean_voice.sh      raw recording → broadcast-ready drop
  speak_drops.py      speak .txt drops with TTS — no external LLM or key
  generate_drops.py   drops written by reubenask; TTS speaks them
  tts.py              TTS adapter (macOS `say`, or ElevenLabs)
  serve_web.py        serves the player page
  stream_to_youtube.sh  optional: audio + looping visual → YouTube Live

music/<show>/         your library, one folder per show (plus any/ catch-all)
drops/SCRIPTS.md      35 scripts to record, five per show
drops/today/<show>/   the talking, by show — same names as music/
web/                  the player page and its disc label
sources/              original recordings and artwork, raw takes for A/B
retired/              drops pulled from rotation, kept just in case
logs/                 icecast + station logs, and the generated icecast.xml
```

## The shows

One set of names for both music and talking — `music/slowdrive/` and
`drops/today/slowdrive/` are the same show. Which folder a file sits in decides
when it airs.

**Monday to Friday daytime**

| show | on air | sounds like |
|---|---|---|
| `firstlight/` | 06:00 – 10:00 | soft, slow, nothing demanding |
| `slowroll/` | 10:00 – 12:00 | warmer, jazzier, properly awake |
| `midday/` | 12:00 – 14:00 | brighter, easy, present but not distracting |
| `longafternoon/` | 14:00 – 17:00 | focus music, minimal, long tracks |
| `slowdrive/` | 17:00 – 20:00 | rush hour — steady, calm, get-home-safe |
| `nightgarage/` | 20:00 – 23:00 | deeper, groove-led, house and garage |
| `smallhours/` | 23:00 – 06:00 | sparse, ambient, almost no percussion |

**Friday 17:00 through Sunday 22:00** — the weekend runs by genre, not by mood.
Each day belongs to a sound, and the nights carry past midnight: Friday night
*is* Saturday 1am.

| show | on air | sounds like |
|---|---|---|
| `afrofriday/` | Fri 17:00 – Sat 06:00 | afrobeats, all night |
| `saturdaysoul/` | Sat 06:00 – 12:00 | r&b and soul, easy start |
| `hiphop/` | Sat 12:00 – 18:00 | hip hop through the afternoon |
| `trap/` | Sat 18:00 – 22:00 | harder, the night building |
| `househours/` | Sat 22:00 – Sun 06:00 | house, peak of the weekend |
| `sundayfolk/` | Sun 06:00 – 14:00 | folk and acoustic, gentle |
| `country/` | Sun 14:00 – 22:00 | country and americana |

Sunday from 22:00 falls back to weekday `smallhours`, easing toward Monday.

`music/any/` is the catch-all for tracks that suit any hour — with a small
library, put everything there and fill the shows in over time.

`drops/today/anytime/` is in the rotation *alongside* the current show, not a
fallback behind it — see the comment in `station.liq` for why that matters.

Show names and hours live in `schedule.json`; the actual switching lives in
`station.liq`. Change both if you rename a show.

## A "drop" is just the talking between songs

Station ID, track credit, a line about the hour. Pre-recorded, dropped into the
stream between records. The station plays `.wav` files out of `drops/today/` and
does not care where they came from.

**Recording them yourself needs none of the rest of this.** Drops are written by reubenask; no external LLMs, no ElevenLabs, no API keys, nothing to pay for:

```bash
# record straight into a show folder, or drag files in from anywhere
drops/today/smallhours/goodnight.wav
drops/today/anytime/station-id.wav
```

Most drops are evergreen — "three in the morning, nothing needs deciding right
now" is true every night forever. Record twenty-five of those once and the
station has a voice indefinitely. Only track credits and topical musings go
stale.

The generator exists for one reason: so the station keeps talking on days you
don't feel like recording. If you're happy recording, skip it — a clone of your
voice is strictly worse than your voice.

## Setup

```bash
brew install liquidsoap icecast ffmpeg && pip install anthropic
```

Change the two passwords in `station.liq`. Icecast's config is generated by
`start.sh` from that same file, so there is nothing else to keep in sync.

Fill the show folders under `music/`. Tag files with `artist` and `title` — the
player reads those tags to name what's on air, and an untagged file shows as
"untitled".

## Run it

Everything at once — Icecast, the station, and the player page:

```bash
./start.sh
```

Then open `http://localhost:8080`. Ctrl-C stops all three; logs land in `logs/`.

It refuses to start if `music/` is empty, reuses an already-running Icecast
instead of fighting it for port 8000, and waits for the mount to actually
appear before claiming to be on air.

### Or start the pieces by hand

```bash
icecast -c logs/icecast.xml    # generated by start.sh
```

```bash
export ANTHROPIC_API_KEY=sk-ant-...
python3 scripts/generate_drops.py --dry-run
```

That prints the day's drops as text without spending any TTS. Read them. Edit
`persona.md` until they sound like you — this is the loop that matters, and it's
worth several passes before you clone anything.

When the writing is right:

```bash
python3 scripts/generate_drops.py
```

```bash
liquidsoap station.liq
```

Tune in at `http://localhost:8000/radio.mp3` — VLC, Safari, or any phone on the
same network via your machine's LAN IP.

## The player page

`web/index.html`, served by `scripts/serve_web.py` on port 8080. Shows what's
playing, the listener count, and which show is currently on air.

It has to be served locally rather than hosted anywhere: the stream lives on
`localhost:8000`, which no hosted page can reach.

Two things that will bite you if you rebuild this page from scratch:

- **No `crossorigin` attribute on the `<audio>` element.** It forces a CORS
  check against Icecast, which sends no `Access-Control-Allow-Origin`, and
  playback dies with `NotSupportedError`. Plain media playback is exempt from
  CORS — the attribute is the only thing that breaks it.
- **The listener count is proxied**, not fetched directly. The page is on :8080
  and Icecast on :8000, so a direct `fetch` is cross-origin and blocked.
  `serve_web.py` re-serves it at `/status.json` on the page's own origin.

## The disc

The label plays `web/label.mp4` — a 4.1s silent loop — with `web/label.png` as
its poster and fallback. It runs only while the station is on air, and never
under `prefers-reduced-motion`.

To rebuild it from a new source clip:

```bash
ffmpeg -ss 2.0 -i sources/label-source.mp4 \
  -filter_complex "[0:v]crop=720:720:280:0,scale=560:560,fps=24,split[a][b];\\
[b]reverse,trim=start_frame=1,setpts=PTS-STARTPTS[r];[a][r]concat=n=2:v=1:a=0[v]" \
  -map "[v]" -an -c:v libx264 -profile:v main -pix_fmt yuv420p \
  -crf 30 -preset slow -movflags +faststart web/label.mp4
```

Three things that filter is doing, and why:

- **Square centre crop.** The label is a circle, so anything near the edge is
  clipped. A centre crop also cut out the backdrop seam that appeared on the
  right at the widest framing.
- **`-ss 2.0`.** The clip pulls back from a close-up; before two seconds the
  characters are large enough that a circular mask cuts their heads off.
- **Ping-pong** (`reverse` + `concat`). The raw clip's first and last frames
  scored 0.69 on SSIM — a visible jump every loop. Playing it forward then
  backward scores 0.95, and the pull-back reads as a slow breathing zoom.

That gets 1.4 MB down to 83 KB.

**Per-show clips**: drop `web/label-<show>.mp4` in and the server serves it for
that show automatically — a calm loop for Small Hours, a livelier one for House
Hours. Same for `label-<show>.png` stills. Missing files fall back.

## Your voice

You have three options, in descending order of how good they sound:

1. **Record yourself.** Best result, costs nothing. Drop `.wav` files into the
   band folders and you're done — no scripts involved at all.
2. **Write the drops, let TTS speak them.** Put `.txt` files in the band folders
   and run `python3 scripts/speak_drops.py`. Defaults to the macOS voice; point
   it at a clone when you want it to sound like you.
3. **Generate and speak automatically.** `scripts/generate_drops.py` — the only
   part that needs an API key.

To clone yourself for options 2 and 3:

1. Record 3–5 minutes of clean speech into `sources/`. Read something in
   the register you actually want on air — calm and unhurried, not performed.
   Consistent room, no music, no background noise.
2. Create the clone in ElevenLabs, grab the voice ID.
3. ```bash
   export TTS_PROVIDER=elevenlabs
   export ELEVENLABS_API_KEY=...
   export ELEVENLABS_VOICE_ID=...
   ```

Instant cloning needs about a minute of audio; professional cloning wants
thirty and sounds meaningfully better. For a voice people hear eight times a
day, the longer sample is worth it.

## Live mic

Point BUTT or Mixxx at `localhost:8005`, mount `live`, and you take over the
stream in real time — music ducks under you, and comes back up when you
disconnect. Same ducking behaviour as the generated drops.

## Daily refresh

Generate each morning at 6am:

```bash
crontab -e
```

```
0 6 * * * cd ~/Desktop/radio && /usr/bin/python3 scripts/generate_drops.py >> generate.log 2>&1
```

Paste fresh material into the signature-content section of `persona.md` each
week. That section is what keeps drops grounded in something real instead of
being generically pleasant — it's the difference between a host and a voice.

## Music rights

Everything here assumes a library you have the right to broadcast: Creative
Commons, royalty-free, or directly licensed. In the US, streaming commercial
music publicly means SoundExchange (about $0.0028 per performance, $1,100/year
minimum per channel in 2026) plus the performing-rights organisations for the
compositions. CC-licensed music avoids all of it. Credit artists on air either
way — that's what the `track_credit` drops are for.
